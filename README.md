A program that outputs one job title, 60 characters or fewer, for the "Weirdest Job Title: Blind Judge Showdown" bounty on make.fun.

The title: **"Professional Sigher at Meetings That Could Have Been Emails"** (59 characters) — a real-sounding job with one hilariously specific twist: someone whose entire profession is sighing, loudly and professionally, at meetings that should have been emails.

## Run it

```sh
python3 main.py
```

It prints exactly the job title to stdout and writes it to the output file (`$MAKEFUN_OUTPUT`, or `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt`).
